# Baukalkulation ES

Web-App für Handwerksbetriebe: Baustellen und Kalkulation, Zeiterfassung, Wochenplanung,
Kunden, Rechnungen/Angebote (ZUGFeRD), Termine sowie Module für Aufmaß, Lager,
VDE 0100 und DIN EN 1090.

- [Entwicklung](entwicklung.md) – Projektstruktur, Tests, Release-Ablauf
